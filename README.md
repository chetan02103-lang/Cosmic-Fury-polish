## 🌌 About the Game

COSMIC FURY is a browser-based space action game where players fight enemies, survive increasingly difficult waves, unlock abilities and face powerful bosses.

## ✨ Features

- 🚀 Space combat and enemy encounters
- 👾 Challenging boss battles
- ⚡ Player upgrades and special abilities
- 🔥 Combo-based gameplay
- 🎯 Increasing difficulty and survival challenges
- 🎵 Game audio and sound effects
